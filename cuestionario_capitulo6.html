Pregunta 01
¿Cuál es la definición más precisa de computación en la nube?
A
Un servicio de internet que almacena fotos y videos en línea
B
Un modelo que permite acceso ubicuo y bajo demanda a recursos informáticos compartidos (servidores, almacenamiento, aplicaciones) a través de internet, con mínimo esfuerzo de gestión
C
El proceso de hacer copias de seguridad de archivos en un disco externo
D
Una red privada de computadoras dentro de una empresa
Correcto: Según la definición del NIST, cloud computing es un modelo de acceso ubicuo, conveniente y bajo demanda a recursos informáticos configurables compartidos que se pueden aprovisionar y liberar rápidamente. Las claves son: acceso por red, bajo demanda, pago por uso y mínima gestión del usuario.
Pregunta 02
¿Qué significa el modelo IaaS (Infraestructura como Servicio)?
A
El proveedor entrega software listo para usar accesible desde el navegador
B
El proveedor entrega la plataforma de desarrollo con bases de datos y herramientas
C
El cliente contrata infraestructura de hardware (servidores virtuales, almacenamiento, redes) y gestiona el SO y las aplicaciones; el proveedor gestiona el hardware físico
D
El cliente solo paga por el almacenamiento utilizado, sin acceso a procesamiento
Correcto: En IaaS el cliente alquila la infraestructura (VMs, almacenamiento, red) pero gestiona el sistema operativo y las aplicaciones. Es como alquilar un terreno: vos construís la casa. Ejemplos: AWS EC2, Azure VMs, Google Compute Engine.
Pregunta 03
¿Qué diferencia al modelo SaaS del PaaS?
A
SaaS es para empresas grandes; PaaS es para usuarios individuales
B
En SaaS el proveedor gestiona todo y el usuario solo usa la aplicación desde el navegador; en PaaS el cliente desarrolla y despliega sus propias aplicaciones sobre la plataforma del proveedor
C
SaaS requiere instalación local; PaaS no
D
No hay diferencia práctica entre ambos modelos
Correcto: En SaaS el usuario solo consume la aplicación (Gmail, Office 365, Zoom) — no instala, no actualiza, no gestiona nada. En PaaS el desarrollador usa la plataforma para construir sus propias aplicaciones (Google App Engine, Azure App Service) sin gestionar el hardware o el SO subyacente.
Pregunta 04
¿Cuáles de los siguientes son ejemplos de SaaS de uso cotidiano?
A
VMware ESXi y Oracle VirtualBox
B
AWS EC2 y Google Compute Engine
C
Microsoft 365, Google Workspace, Gmail y Zoom
D
Windows Server y Ubuntu Server
Correcto: Microsoft 365 (Word, Excel, Teams online), Google Workspace (Gmail, Drive, Docs) y Zoom son ejemplos clásicos de SaaS: el usuario accede desde el navegador o app sin instalar ni gestionar nada. El proveedor administra toda la infraestructura, plataforma y aplicación.
Pregunta 05
¿Cuál es la principal ventaja del modelo de pago en la nube (pay-as-you-go) respecto al modelo de hardware propio?
A
El hardware propio es siempre más seguro que la nube
B
Con pay-as-you-go solo se paga por los recursos efectivamente usados, sin invertir en hardware que puede estar subutilizado, y se puede escalar o reducir en minutos
C
El pago en la nube siempre es más barato que tener servidores propios
D
Con pay-as-you-go nunca hay que preocuparse por el uso de recursos
Correcto: El modelo pay-as-you-go elimina la inversión inicial en hardware y permite pagar solo por lo consumido. Un servidor físico comprado puede estar usando el 10% de su capacidad, pero el costo fijo es el mismo. En la nube, si usás el 10%, pagás el 10%. La escalabilidad inmediata (más o menos recursos en minutos) es otra ventaja clave.
Pregunta 06
¿Qué es una Máquina Virtual (VM)?
A
Un servidor físico de alta potencia dedicado a un solo cliente
B
Una computadora virtual que corre sobre hardware físico compartido, creyendo que tiene hardware exclusivo, administrada por un hipervisor
C
Un simulador de hardware para probar programas antes de compilarlos
D
Una copia de seguridad del sistema operativo almacenada en la red
Correcto: Una VM es una computadora virtual creada por software. Tiene su propio SO (invitado), aplicaciones y archivos, pero comparte el hardware físico del host. Cada VM está aislada de las demás: un problema en una VM no afecta a las otras. El hipervisor gestiona la asignación de recursos.
Pregunta 07
¿Cuál es el principal problema del modelo de servidores dedicados tradicionales que la virtualización resuelve?
A
Que los servidores dedicados son demasiado pequeños para instalar múltiples sistemas operativos
B
El desperdicio de recursos: cada servidor usa solo una fracción de su capacidad, pero genera costos fijos de hardware, espacio, energía y mantenimiento
C
Que los servidores dedicados solo pueden ejecutar software de un fabricante específico
D
Que los servidores dedicados no pueden conectarse a internet
Correcto: Un servidor de email puede usar solo el 10% de su CPU y RAM. Con hardware dedicado, ese 90% desperdiciado tiene el mismo costo fijo. La virtualización permite consolidar múltiples servicios en un solo servidor físico, usando los recursos de forma eficiente y reduciendo drásticamente la proliferación de servidores.
Pregunta 08
¿Qué es un hipervisor y cuál es su función principal?
A
Un procesador de alta velocidad diseñado específicamente para virtualización
B
Software que crea, ejecuta y gestiona máquinas virtuales, administrando la asignación de recursos físicos (CPU, RAM, disco) entre las VMs
C
Un sistema de almacenamiento en red para guardar imágenes de VMs
D
Un protocolo de red para comunicar máquinas virtuales entre sí
Correcto: El hipervisor (VMM - Virtual Machine Monitor) es el software que hace posible la virtualización. Crea y gestiona las VMs, asigna recursos físicos (CPU, RAM, almacenamiento, red) a cada VM, y las aísla entre sí para que no interfieran. Sin hipervisor no hay virtualización.
Pregunta 09
¿Cuál es la diferencia fundamental entre un hipervisor de Tipo 1 y uno de Tipo 2?
A
El Tipo 1 crea más VMs que el Tipo 2; el Tipo 2 es más seguro
B
El Tipo 1 corre directamente sobre el hardware sin SO host (bare-metal); el Tipo 2 corre como aplicación sobre un SO host existente
C
El Tipo 1 es gratuito; el Tipo 2 siempre tiene costo
D
El Tipo 1 es para Windows; el Tipo 2 es para Linux
Correcto: Tipo 1 (bare-metal): el hipervisor ES el SO del servidor, corre directamente sobre el hardware. Máximo rendimiento, usado en datacenters. Tipo 2 (hosted): el hipervisor es una aplicación que corre sobre un SO host (Windows, Linux). Más fácil de instalar, usado en PCs y notebooks de usuarios y desarrolladores.
Pregunta 10
¿Cuál de los siguientes es un hipervisor de Tipo 1 (bare-metal)?
A
Oracle VirtualBox
B
VMware Workstation
C
VMware vSphere/ESXi
D
Parallels Desktop
Correcto: VMware vSphere/ESXi es un hipervisor de Tipo 1: corre directamente sobre el hardware del servidor sin necesitar un SO host. Es el estándar empresarial en datacenters. VirtualBox, VMware Workstation y Parallels son hipervisores de Tipo 2 que corren como aplicaciones sobre Windows, Linux o macOS.
Pregunta 11
¿Cómo puede un técnico en formación practicar con virtualización en su propia notebook con Windows 11 Pro sin instalar software adicional?
A
Descargando VMware Workstation de forma gratuita desde la web oficial
B
Activando Hyper-V desde "Características de Windows", que está incluido en Windows 11 Pro sin costo adicional
C
Usando el modo de compatibilidad de Windows 11 para ejecutar sistemas operativos antiguos
D
Instalando una segunda copia de Windows 11 en una partición separada del disco
Correcto: Windows 11 Pro incluye Hyper-V, un hipervisor de Microsoft activable desde "Características de Windows" (Panel de Control). Sin costo adicional, permite crear y gestionar VMs con Linux, Windows Server u otros sistemas operativos. Es ideal para practicar en el laboratorio sin hardware adicional.
Pregunta 12
¿Para qué sirve un "snapshot" de una máquina virtual?
A
Para capturar una imagen de pantalla de lo que muestra la VM
B
Para guardar el estado completo de la VM en un momento dado, pudiendo restaurarla exactamente a ese punto si algo sale mal
C
Para clonar la VM y crear una copia idéntica en otro servidor
D
Para pausar la VM y liberar recursos temporalmente para el host
Correcto: Un snapshot guarda el estado completo de la VM (memoria, disco, configuración) en un instante. Permite restaurar la VM exactamente a ese estado anterior. Es muy útil antes de instalar software riesgoso, aplicar actualizaciones o realizar cambios de configuración: si algo falla, se restaura el snapshot en segundos.
Pregunta 13
¿Cuál es la principal diferencia entre un contenedor Docker y una máquina virtual?
A
Los contenedores son más seguros que las VMs porque tienen más capas de aislamiento
B
Los contenedores virtualizan a nivel de aplicación compartiendo el kernel del SO host, son más ligeros (MB vs GB) e inician en milisegundos; las VMs virtualizan hardware completo incluyendo SO
C
Los contenedores solo funcionan en Linux; las VMs funcionan en cualquier SO
D
Los contenedores son una versión simplificada de las VMs, con menos funcionalidades
Correcto: Las VMs incluyen un SO completo (GB de tamaño, minutos para iniciar). Los contenedores Docker solo incluyen la aplicación y sus dependencias, compartiendo el kernel del SO host (MB de tamaño, milisegundos para iniciar). Los contenedores son más eficientes para microservicios y despliegue continuo; las VMs ofrecen mayor aislamiento.
Pregunta 14
¿Qué es Kubernetes y en qué contexto se usa?
A
Un tipo de base de datos NoSQL desarrollado por Google para cloud
B
Un sistema open source de orquestación de contenedores que automatiza el despliegue, escalado y gestión de cientos o miles de contenedores en producción
C
Un hipervisor de Tipo 1 desarrollado por Google para datacenters
D
Un protocolo de red para comunicar contenedores entre distintos proveedores cloud
Correcto: Kubernetes (K8s) es el estándar open source de Google para orquestación de contenedores. Cuando hay cientos o miles de contenedores en producción, K8s los gestiona automáticamente: escala según demanda, reinicia los que fallan, distribuye tráfico y gestiona actualizaciones sin downtime. Es la tecnología base de los tres grandes cloud providers.
Pregunta 15
¿Qué es el modelo de nube híbrida y por qué es tan adoptado en 2026?
A
Una nube que combina servicios de AWS y Azure simultáneamente
B
Una combinación de nube pública y privada: las cargas sensibles van a la privada con mayor control, y las que necesitan escala van a la pública, obteniendo lo mejor de ambos modelos
C
Una nube que funciona tanto desde el navegador como desde aplicaciones instaladas localmente
D
Un modelo donde los datos se distribuyen automáticamente entre múltiples regiones geográficas
Correcto: La nube híbrida combina infraestructura privada (datacenter propio, mayor control y seguridad) con nube pública (mayor escala y elasticidad). Las cargas de trabajo críticas o con datos sensibles van a la privada; las que necesitan escalar rápidamente van a la pública. Es el modelo más adoptado por grandes empresas en 2025–2026.
Pregunta 16
¿Qué es el serverless computing y cuál es su principal ventaja?
A
Computación que no usa servidores físicos, basada completamente en computadoras personales
B
Modelo en que el desarrollador solo escribe código (funciones), el proveedor gestiona toda la infraestructura y cobra solo por cada ejecución, sin necesidad de aprovisionar servidores
C
Computación distribuida entre miles de dispositivos IoT sin servidor central
D
Un modelo de nube privada que elimina la necesidad de conexión a internet
Correcto: En serverless (AWS Lambda, Azure Functions, Google Cloud Functions) el desarrollador solo escribe la función de código. El proveedor la ejecuta solo cuando se necesita, escala automáticamente y cobra por milisegundo de ejecución. No hay servidores que aprovisionar, parchear ni mantener. Ideal para tareas event-driven y microservicios.

Pregunta 18
¿Qué es Windows 365 Cloud PC y qué modelo de cloud representa?
A
Una versión ligera de Windows 11 para dispositivos con poca RAM, es un modelo IaaS
B
Un PC Windows completo en la nube al que se accede desde cualquier dispositivo con navegador, es el ejemplo más claro de SaaS de sistema operativo
C
Un servicio de backup de Windows 11 en la nube de Microsoft, es un modelo PaaS
D
Una plataforma para desarrolladores que quieren crear apps para Windows, es un modelo PaaS

Pregunta 19
¿Qué problema resuelve el Edge Computing y en qué aplicaciones es crítico?
A
El costo excesivo de los proveedores cloud, procesando datos localmente para pagar menos
B
La latencia: al procesar datos cerca del origen (dispositivos IoT, fábricas, vehículos) en lugar de enviarlos a una nube central, reduce el tiempo de respuesta a milisegundos
C
La seguridad de los datos al cifrarlos en el dispositivo antes de enviarlos a la nube
D
La falta de cobertura de internet en zonas remotas, creando mini-nubes locales
Correcto: Edge Computing reduce la latencia procesando datos en el borde de la red (cerca de donde se generan). Esto es crítico en aplicaciones donde milisegundos importan: vehículos autónomos (deben reaccionar antes de consultar la nube), cirugía robótica remota, control industrial en tiempo real e IoT de alta frecuencia.
Pregunta 20
¿Qué ventaja tiene la virtualización sobre los servidores dedicados en cuanto a recuperación ante desastres?
A
Las VMs no pueden sufrir fallos porque el hipervisor las protege automáticamente
B
La imagen de una VM se puede guardar como archivo, copiar a otro servidor y restaurar rápidamente; con hardware dedicado hay que reparar o reemplazar físicamente el servidor antes de restaurar
C
Las VMs no requieren hardware físico, por lo que no pueden sufrir fallas de hardware
D
Los proveedores cloud garantizan por contrato que nunca habrá pérdida de datos
Correcto: Una VM es un archivo (o conjunto de archivos) que se puede copiar, mover y restaurar en cualquier servidor compatible. Si el servidor físico falla, la VM se levanta en otro host en minutos. Con hardware dedicado, una falla requiere reparar o reemplazar el equipo físico (horas o días) antes de poder restaurar el servicio.
