Pregunta 01
¿Qué es el Panel de Control de Herramientas Administrativas en Windows?
A
Un panel donde se configuran la apariencia y los colores del escritorio de Windows
B
Un conjunto de accesos directos a utilidades que permiten supervisar y configurar el funcionamiento de Windows, como Administración de equipos, Visor de eventos, Servicios y más
C
Una sección del Panel de Control que gestiona exclusivamente los usuarios y sus contraseñas
D
El menú de configuración de red e internet de Windows
Correcto — Opción B: Las Herramientas Administrativas son un conjunto de accesos directos a utilidades de supervisión y configuración de Windows. Incluyen: Computer Management, Event Viewer, Services, Performance Monitor, Print Management, Registry Editor, System Configuration, Windows Memory Diagnostic, entre otras. Evolucionó con cada versión de Windows.
Pregunta 02
¿Cuáles son los tres grupos de utilidades que proporciona la consola de Administración de Computadoras (compmgmt.msc)?
A
Hardware, Software y Red
B
Herramientas del sistema, Almacenamiento, y Servicios y aplicaciones
C
Usuarios, Discos y Rendimiento
D
Seguridad, Actualizaciones y Configuración
Correcto — Opción B: Computer Management organiza sus herramientas en tres grupos: 1) Herramientas del sistema (Task Scheduler, Event Viewer, Shared Folders, Local Users and Groups, Performance, Device Manager), 2) Almacenamiento (Disk Management) y 3) Servicios y aplicaciones (Services, WMI Control). También permite gestionar equipos remotos.
Pregunta 03
En el Visor de Eventos, ¿qué nivel indica que un evento requiere atención inmediata y generalmente se relaciona con fallas o bloqueos del sistema?
A
Error
B
Advertencia
C
Crítico
D
Información
Correcto — Opción C: El nivel Crítico es el más grave: indica que se requiere atención inmediata y generalmente está relacionado con fallas o bloqueos del sistema o software. Error indica un problema que no requiere acción inmediata; Advertencia es un posible problema; Información indica un evento exitoso.
Pregunta 04
¿Cuál de los siguientes grupos de usuarios locales en Windows tiene control total del equipo y acceso a todas las carpetas?
A
Usuarios, porque son la cuenta predeterminada para todos
B
Invitados, porque tienen acceso temporal sin restricciones
C
Administradores, con control total del equipo y acceso a todas las carpetas del sistema
D
Power Users, porque tienen más privilegios que los usuarios estándar
Correcto — Opción C: El grupo Administradores tiene control total del equipo y acceso a todas las carpetas. Los Usuarios pueden realizar tareas comunes (ejecutar apps, imprimir) con un perfil persistente. Los Invitados tienen un perfil temporal creado al iniciar sesión y eliminado al cerrarla, y están deshabilitados por defecto.
Pregunta 05
¿Qué es un servicio en Windows y qué buena práctica de seguridad aplica a su gestión?
A
Es un tipo de archivo del sistema; siempre se deben iniciar todos los servicios disponibles para garantizar el máximo rendimiento
B
Es una aplicación de usuario que se ejecuta en primer plano; se recomienda activarlos todos al inicio
C
Es un tipo de aplicación que se ejecuta en segundo plano; la buena práctica es iniciar solo los servicios necesarios para reducir la superficie de ataque
D
Es un controlador de hardware; debe estar siempre en modo automático para garantizar compatibilidad
Correcto — Opción C: Un servicio es una aplicación que se ejecuta en segundo plano para cumplir una función específica o esperar solicitudes. La consola services.msc permite gestionarlos. La buena práctica de seguridad es iniciar solo los servicios necesarios, ya que cada servicio activo es una posible superficie de ataque para exploits o escalada de privilegios.
Pregunta 06
¿Para qué sirve la herramienta msinfo32 y cómo se abre?
A
Para configurar el arranque seguro de Windows; se abre desde la BIOS presionando F2
B
Para recopilar y mostrar información detallada del hardware, controladores, componentes y software del equipo; se abre ejecutando msinfo32 desde Win+R o el símbolo del sistema
C
Para gestionar los servicios del sistema; se abre desde el Panel de Control → Servicios
D
Para diagnosticar problemas de DirectX en videojuegos; se abre desde la Tienda Microsoft
Correcto — Opción B: msinfo32 (Información del sistema) recopila y muestra datos detallados sobre el equipo: SO, versión, procesador, BIOS, tipo de sistema, drivers, componentes de hardware y software. Se puede exportar un informe completo. Se abre con Win+R → msinfo32, o desde el símbolo del sistema.
Pregunta 07
¿Qué hace la herramienta msconfig y para qué se usa principalmente?
A
Configura la conexión a internet y los servidores DNS del equipo
B
Identifica y resuelve problemas que impiden que Windows inicie correctamente, permitiendo configurar el tipo de arranque, deshabilitar servicios y administrar el inicio
C
Gestiona las actualizaciones automáticas de Windows y las aplicaciones instaladas
D
Permite crear y gestionar máquinas virtuales dentro de Windows 10
Correcto — Opción B: msconfig (Configuración del sistema) es la herramienta de diagnóstico de arranque. Sus pestañas permiten: elegir tipo de inicio (Normal, Diagnóstico, Selectivo), configurar el Arranque Seguro, deshabilitar servicios individuales para diagnóstico, gestionar programas de inicio y acceder a herramientas de diagnóstico. Se ejecuta con Win+R → msconfig.
Pregunta 08
¿Qué es el Registro de Windows y cómo se organiza internamente?
A
Es un archivo de texto donde Windows guarda el historial de eventos del sistema, organizado por fechas
B
Es la base de datos central donde se almacena toda la configuración de Windows y aplicaciones, organizada en una jerarquía de claves y subclaves (hasta 512 niveles), almacenada como archivos de base de datos llamados colmenas
C
Es el directorio donde Windows guarda los archivos temporales y la caché del navegador
D
Es una lista de todos los programas instalados en el sistema, organizada alfabéticamente
Correcto — Opción B: El Registro de Windows es la base de datos central que almacena toda la configuración del SO y las aplicaciones. Se organiza jerárquicamente en claves y subclaves (hasta 512 niveles de profundidad), almacenadas físicamente como archivos llamados colmenas. Cada clave tiene valores con nombre, tipo de datos y datos que le indican a Windows cómo operar.
Pregunta 09
¿Qué clave raíz del Registro almacena información sobre el estado físico de la computadora, incluyendo la configuración de hardware y Plug and Play?
A
HKEY_CURRENT_USER
B
HKEY_CLASSES_ROOT
C
HKEY_LOCAL_MACHINE
D
HKEY_CURRENT_CONFIG
Correcto — Opción C: HKEY_LOCAL_MACHINE (HKLM) almacena información sobre el estado físico del equipo: configuración de hardware, información de inicio de sesión y seguridad de red, Plug and Play, etc. HKEY_CURRENT_USER tiene las preferencias del usuario actual; HKEY_CLASSES_ROOT tiene las asociaciones de archivos; HKEY_CURRENT_CONFIG tiene el perfil de hardware actual.
Pregunta 10
¿Cuál es el riesgo principal de usar incorrectamente el Editor del Registro (regedit)?
A
Que se pierda la conexión a internet hasta el próximo reinicio del sistema
B
Que las imágenes del fondo de pantalla se borren permanentemente
C
Que se causen problemas de hardware, aplicaciones o del propio SO, que en casos graves pueden requerir reinstalar el sistema operativo
D
Que el antivirus detecte el editor como software malicioso y lo elimine
Correcto — Opción C: El uso incorrecto de regedit puede causar problemas de hardware, aplicaciones y del SO, incluyendo casos tan graves que requieren reinstalar Windows. Por eso siempre se debe hacer una copia de seguridad del registro antes de modificarlo. regedit solo se puede abrir desde una búsqueda o desde el símbolo del sistema.
Pregunta 11
¿Qué es la Microsoft Management Console (MMC) y qué son los complementos (snap-ins)?
A
Un navegador web de Microsoft para administrar servidores remotos vía internet
B
Una aplicación que permite crear consolas de administración personalizadas agregando herramientas llamadas complementos; estas consolas se pueden guardar y reutilizar para propósitos específicos
C
Un emulador de terminal para ejecutar comandos de administración en Linux desde Windows
D
La consola de PowerShell con soporte para módulos de administración remota
Correcto — Opción B: La MMC es un marco vacío al que se agregan complementos (snap-ins) — utilidades como Disk Management, Event Viewer, Device Manager, Certificates, etc. También permite agregar enlaces web, carpetas y controles ActiveX. Se guarda la consola con exactamente las herramientas necesarias para una tarea administrativa específica.
Pregunta 12
¿Qué muestra DxDiag y para qué aplicaciones es especialmente útil?
A
Muestra el estado de todos los discos del sistema; es útil para detectar sectores dañados
B
Muestra información de los controladores y componentes de DirectX instalados (gráficos, audio, input); es especialmente útil para diagnosticar problemas en videojuegos y aplicaciones multimedia
C
Muestra el diagnóstico de la memoria RAM; es útil para detectar errores de hardware
D
Muestra el estado de los servicios de red activos; es útil para troubleshooting de conectividad
Correcto — Opción B: DxDiag (DirectX Diagnostic Tool) informa sobre todos los controladores y componentes DirectX: versión de DirectX, adaptador de video, drivers de audio e input. DirectX es la API multimedia de Windows para gráficos 2D/3D, audio y codecs. Es la herramienta de referencia cuando un juego o aplicación multimedia falla y se sospecha del driver de video o audio.

A
Solo desde el Explorador de archivos haciendo doble clic en "Este equipo"
B
Haciendo clic derecho en "Este equipo" y seleccionando Administrar, o desde el menú Win+X y seleccionando Administración de discos

Solo a través del símbolo del sistema con el comando diskpart

Desde Configuración → Actualización y seguridad → Recuperación

Pregunta 14
¿Qué significa el estado "Ilegible" en una unidad dentro de Administración de Discos?
A
El disco está encriptado con BitLocker y necesita la clave de recuperación
B
El disco es nuevo y aún no fue inicializado con una firma válida
C
El disco es un disco externo proveniente de otra computadora con Windows
D
El disco básico o dinámico sufrió una falla de hardware, daños en la estructura o errores de entrada/salida
Correcto — Opción D: El estado "Ilegible" indica que el disco (básico o dinámico) experimentó una falla de hardware, daños en la estructura del disco o errores de E/S (Input/Output). El estado "Sin inicializar" corresponde a un disco nuevo sin firma; "Externo" es para discos dinámicos de otra PC; "En línea" es el estado normal y correcto.
Pregunta 15
¿Qué es montar una imagen ISO en Windows y cómo se accede al contenido montado?
A
Es grabar el archivo ISO en un pendrive; el contenido se accede desde el USB
B
Es hacer que el archivo ISO sea accesible como una unidad virtual sin grabarlo en ningún medio; Windows lo muestra como una unidad de medios extraíble con su propia letra de unidad
C
Es comprimir el archivo ISO para reducir su tamaño en el disco duro
D
Es convertir el archivo ISO al formato VHD para usarlo en máquinas virtuales
Correcto — Opción B: Montar una ISO significa hacer que su contenido sea legible como una unidad física sin grabarlo. En Windows: seleccionar el ISO en el Explorador → pestaña Administrar → Montar. El ISO aparece como una unidad DVD Drive con su propia letra, accesible desde el Explorador de archivos. Es muy útil para instalar software o acceder a contenido sin necesidad de un DVD físico.
Pregunta 16
¿Por qué NO se debe desfragmentar un SSD (disco de estado sólido)?
A
Porque los SSD no pueden fragmentarse al no tener partes móviles, por lo que la operación es completamente innecesaria
B
Porque la desfragmentación en SSD no mejora el rendimiento (ya se optimizan con su controladora y TRIM) y genera ciclos de escritura innecesarios que reducen la vida útil del dispositivo
C
Porque Windows no tiene una herramienta de desfragmentación compatible con unidades SSD
D
Porque los SSD solo pueden ser optimizados por el fabricante mediante actualizaciones de firmware
Correcto — Opción B: Los SSD tienen acceso uniforme a todas las celdas (no importa la ubicación física de los datos), por lo que la fragmentación no afecta el rendimiento. Además, la desfragmentación genera ciclos de escritura innecesarios que reducen la vida útil del SSD (que tiene ciclos de escritura limitados). Los SSD se optimizan con su propia controladora y el comando TRIM.
Pregunta 17
¿Qué extensiones de archivo tiene típicamente un instalador de aplicaciones en Windows?
A
.ZIP y .RAR
B
.ISO y .IMG
C
.EXE o .MSI (Microsoft Silent Installer)
D
.BAT y .CMD
Correcto — Opción C: Los instaladores de Windows tienen típicamente extensión .EXE (ejecutable) o .MSI (Microsoft Installer, anteriormente llamado Microsoft Silent Installer). Si la instalación no inicia automáticamente al insertar el medio, se busca y ejecuta manualmente el archivo .EXE o .MSI en los medios de instalación.
Pregunta 18
¿Cómo se configura el Modo de Compatibilidad para una aplicación antigua que no funciona correctamente en Windows 10?
A
Reinstalando el sistema operativo en modo legado desde la configuración de Windows Update
B
Clic derecho en el ejecutable → Propiedades → pestaña Compatibilidad → configurar la versión de Windows a emular o ejecutar el Solucionador de problemas de compatibilidad
C
Abriendo msconfig y seleccionando el modo de inicio de diagnóstico para emular Windows anterior
D
Desde la Tienda Microsoft → sección "Apps legado" → seleccionar la versión compatible
Correcto — Opción B: El Modo de Compatibilidad se configura desde las propiedades del ejecutable: clic derecho → Abrir ubicación del archivo → clic derecho en el .exe → Propiedades → pestaña Compatibilidad. Desde ahí se puede ejecutar el Solucionador automático o configurar manualmente la emulación de Windows 7, 8, Vista, XP, etc.
Pregunta 19
¿Por qué Microsoft recomienda usar "Programas y características" del Panel de Control para desinstalar apps, en lugar de borrar manualmente los archivos?
A
Porque es el único método que elimina el icono del escritorio además del programa
B
Porque elimina correctamente todos los archivos instalados y las entradas del Registro, evitando que queden residuos que consumen espacio y ralentizan el sistema
C
Porque el borrado manual de carpetas de programa está bloqueado por Windows por razones de seguridad
D
Porque genera automáticamente una copia de seguridad del programa antes de eliminarlo
Correcto — Opción B: Borrar manualmente los archivos de una app deja entradas huérfanas en el Registro y otros archivos dispersos por el sistema, que consumen espacio y pueden ralentizar el registro. Programas y características (appwiz.cpl) usa el propio desinstalador de la aplicación, que elimina todos los archivos, entradas del registro y configuraciones creadas durante la instalación.
Pregunta 20
¿Por qué permitir que los usuarios instalen software libremente en equipos corporativos representa un riesgo de seguridad?
A
Porque puede aumentar el consumo de ancho de banda de la red al descargar actualizaciones
B
Porque los usuarios pueden ser engañados para descargar malware que puede robar o destruir datos e infectar todos los equipos conectados a la red corporativa
C
Porque instalar demasiados programas fragmenta el disco duro y reduce el espacio disponible
D
Porque Windows Defender se desactiva automáticamente cuando detecta software de terceros
Correcto — Opción B: El riesgo principal es el malware: los usuarios pueden ser víctimas de ingeniería social y descargar software malicioso disfrazado de aplicación legítima. Este malware puede robar credenciales, cifrar datos (ransomware) o propagarse a otros equipos de la red. El técnico debe aplicar políticas de instalación (AppLocker, GPO) y mantener Windows Defender actualizado.
