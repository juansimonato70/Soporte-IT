Pregunta 01
¿Cuál es la función principal de una pulsera antiestática en el taller de PC?
A
Proteger las manos de cortaduras con los bordes del gabinete
B
Igualar el potencial eléctrico entre el técnico y el equipo, evitando descargas electroestáticas (ESD) que dañen los componentes
C
Medir la resistencia de los componentes electrónicos
D
Mejorar la conducción eléctrica al tocar componentes
Correcto: La pulsera antiestática conecta el cuerpo del técnico al chasis metálico del equipo, igualando potenciales eléctricos. Esto evita que una descarga de electricidad estática (ESD) dañe componentes sensibles como la CPU, RAM o tarjetas de expansión.
Pregunta 02
¿Por qué se recomienda fotografiar el interior del equipo antes de comenzar el desarmado?
A
Para tener evidencia en caso de demanda legal
B
Para poder ver mejor los tornillos pequeños
C
Para registrar el estado original de los cables, posición de componentes y conexiones, y poder referenciarla durante el armado
D
Para cumplir con una normativa de calidad ISO
Correcto: La fotografía previa sirve como referencia visual del estado original. Al armar nuevamente, es posible verificar dónde iba cada cable, conector y componente, evitando errores de reinstalación.
Pregunta 03
¿Qué herramienta se usa para aplicar o retirar tornillos de cabeza Phillips en el interior de un gabinete?
A
Destornillador de punta plana
B
Destornillador estrella (Phillips) magnetizado #1 y #2
C
Llave Allen de 3mm
D
Pinza de corte
Correcto: La gran mayoría de tornillos en gabinetes y componentes de PC son de cabeza Phillips. Se usan puntas #1 (tornillos pequeños) y #2 (tornillos del gabinete y fuente). La punta magnetizada facilita el trabajo en espacios reducidos.
Pregunta 04
¿Cuál es el orden correcto de armado de una PC?
A
Fuente → GPU → CPU → RAM → Placa base → Almacenamiento
B
RAM → CPU → Placa base → Fuente → GPU → Cables
C
Placa base → CPU + pasta térmica → RAM → Fuente → Almacenamiento → Tarjetas PCIe → Cables
D
CPU → Placa base → Cables → RAM → Fuente → GPU
Correcto: El orden recomendado prioriza instalar primero los componentes que quedan debajo o son más difíciles de acceder luego. La placa base va primero, luego CPU y RAM, y los cables al final para gestionar mejor el cableado.
Pregunta 05
¿Cuánta pasta térmica se debe aplicar en un procesador según la buena práctica?
A
Cubrir toda la superficie del procesador con una capa uniforme
B
Una pequeña cantidad del tamaño de un grano de arroz en el centro
C
Aplicarla solo en los bordes del procesador
D
Ninguna, los procesadores modernos no necesitan pasta térmica
Correcto: El método del "punto central" es el más recomendado: una cantidad equivalente a un grano de arroz en el centro. Al montar el disipador, la presión distribuye la pasta. Usar demasiada puede causar cortocircuito si se derrama hacia los pines.
Pregunta 06
¿Qué ocurre si al instalar la CPU se fuerza el mecanismo del socket cuando la CPU no está bien orientada?
A
El sistema operativo detecta el error y lo corrige automáticamente
B
Se doblan o rompen los pines del socket, dañando irreparablemente la placa base o el procesador
C
La CPU entra igual pero el equipo funciona más lento
D
Se activa un mecanismo de protección que impide el encendido
Correcto: Si se fuerza la CPU con orientación incorrecta, los pines del socket (AMD) o de la CPU (Intel LGA) se doblan o rompen. Este daño generalmente es irreparable y muy costoso.
Pregunta 07
¿Por qué NUNCA se debe abrir una fuente de alimentación en el taller?
A
Porque pierde la garantía del fabricante
B
Porque contiene capacitores que pueden mantener voltajes letales incluso estando desenchufada
C
Porque el polvo interno contamina los demás componentes
D
Porque no tiene tornillos accesibles desde el exterior
Correcto: Los capacitores de las fuentes de alimentación pueden retener cargas de hasta 400V o más durante horas después de desenchufar el equipo. Las fuentes defectuosas deben reemplazarse, no repararse en el taller.
Pregunta 08
¿Qué tipo de memoria RAM utilizan los servidores para mayor confiabilidad?
A
DDR4 de alta frecuencia (overclocked)
B
RAM ECC (Error Correcting Code), que detecta y corrige errores de bits en tiempo real
C
LPDDR5, la misma que usan las laptops de gama alta
D
RAM virtual implementada en el procesador
Correcto: La RAM ECC detecta y corrige errores de un bit en tiempo real. En servidores de bases de datos o sistemas críticos, un bit incorrecto puede corromper datos. La ECC previene estos errores de forma continua y transparente.
Pregunta 09
¿Cuál es la principal diferencia entre una PC de escritorio y un servidor en cuanto a disponibilidad operativa?
A
Los servidores solo se usan en empresas grandes, las PCs en pequeñas
B
Un servidor está diseñado para funcionar 24/7/365 con alta disponibilidad, mientras que una PC opera típicamente 8-10 horas diarias con downtime aceptable
C
Los servidores se apagan automáticamente de noche para ahorrar energía
D
La PC y el servidor tienen el mismo diseño; solo difieren en el software instalado
Correcto: Los servidores están diseñados para disponibilidad continua. El tiempo de actividad se mide en "nines": 99.999% ("cinco nueves") equivale a menos de 5,26 minutos de downtime por año.
Pregunta 10
¿Qué es el factor de forma "rack" en servidores y cómo se mide?
A
Es el color del gabinete del servidor
B
Es el formato de montaje en bastidores estándar; el tamaño se mide en unidades de rack (U), donde 1U = 44,45 mm de alto
C
Es el tipo de socket de CPU que usa el servidor
D
Es la cantidad de discos que puede alojar un servidor
Correcto: El factor de forma rack permite montar múltiples servidores en un bastidor estándar de 19". La altura se mide en unidades U (1U = 44,45 mm). Un servidor 1U es muy compacto; un 4U tiene más espacio para componentes.
Pregunta 11
¿Qué es iLO/iDRAC y para qué sirve en los servidores?
A
Son protocolos de red para conectar múltiples servidores en clúster
B
Son sistemas de gestión remota fuera de banda que permiten administrar el servidor (incluso apagado) por red, ver la consola, y diagnosticar fallos sin estar físicamente presente
C
Son sistemas de almacenamiento en la nube propietarios de HP y Dell
D
Son tipos especiales de conectores de red para servidores
Correcto: iLO (HP) e iDRAC (Dell) son controladores de gestión de placa base (BMC). Funcionan de forma independiente al sistema principal y permiten encender/apagar el servidor, ver la consola y diagnosticar problemas remotamente.
Pregunta 12
¿Qué significa que un componente sea "hot-swap"?
A
Que el componente opera a temperaturas muy altas
B
Que puede ser reemplazado con el servidor encendido y en funcionamiento, sin interrumpir el servicio
C
Que necesita un adaptador especial para conectarse
D
Que solo puede instalarse en servidores de alto voltaje
Correcto: Hot-swap es la capacidad de insertar o extraer un componente mientras el sistema está encendido y operativo. El sistema detecta el cambio automáticamente sin necesidad de reinicio, manteniendo la disponibilidad del servicio.
Pregunta 13
¿Cuáles de los siguientes componentes son típicamente hot-swap en un servidor?
A
CPU y RAM
B
Placa base y tarjetas PCIe
C
Discos rígidos, fuentes de alimentación y módulos de ventiladores
D
Procesadores y módulos de memoria RAM ECC
Correcto: En la gran mayoría de los servidores, los componentes hot-swap son: discos rígidos (en caddies), fuentes de alimentación redundantes y módulos de ventiladores. La CPU, RAM y placa base NO son hot-swap y requieren apagado del equipo.
Pregunta 14
¿Qué sucede en el sistema cuando se extrae un disco hot-swap defectuoso de un RAID y se inserta uno nuevo?
A
El servidor se reinicia automáticamente para detectar el nuevo disco
B
El RAID controller detecta el nuevo disco y comienza automáticamente la reconstrucción del RAID, restaurando la redundancia sin interrumpir el servicio
C
El nuevo disco queda en standby hasta que el administrador lo active manualmente
D
El servidor pierde todos los datos del RAID y hay que restaurar desde backup
Correcto: El RAID controller monitorea los discos constantemente. Al detectar la inserción de un disco nuevo, inicia automáticamente el proceso de reconstrucción ("rebuild") copiando datos desde los discos restantes, sin interrumpir el servicio.
Pregunta 15
Un técnico necesita reemplazar una fuente de alimentación en un servidor encendido con dos fuentes en modo 1+1. ¿Cuál es el procedimiento correcto?
A
Apagar el servidor, reemplazar la fuente, luego encender nuevamente
B
Identificar la fuente defectuosa por su LED de error, extraerla en caliente, insertar la nueva fuente y verificar que el LED de estado sea verde
C
Desconectar el cable de la fuente defectuosa primero, luego extraerla
D
Reemplazar ambas fuentes simultáneamente para mantener el balance de carga
Correcto: En modo 1+1, cada fuente puede alimentar todo el servidor sola. El procedimiento hot-swap es: identificar la fallada (LED naranja/rojo), extraerla directamente, insertar la nueva y verificar que el LED cambie a verde.
Pregunta 16
¿Qué es un SPOF (Single Point of Failure) en infraestructura de servidores?
A
Un tipo de protocolo de red para servidores críticos
B
Un componente cuya falla única causaría la caída de todo el sistema; el diseño con redundancia busca eliminarlos
C
Un registro de errores en el sistema operativo del servidor
D
Un tipo de disco duro de alta velocidad para servidores
Correcto: SPOF es cualquier componente cuya falla única provoca que todo el sistema deje de funcionar. El diseño de infraestructura crítica busca identificar y eliminar todos los SPOF mediante redundancia.
Pregunta 17
¿Cuál es la diferencia entre RAID 1 y RAID 5?
A
RAID 1 usa más discos pero es más lento; RAID 5 usa menos discos pero es más rápido
B
RAID 1 espeja los datos en 2 discos (soporta falla de 1); RAID 5 distribuye datos y paridad en 3+ discos (soporta falla de 1 disco con mejor aprovechamiento del espacio)
C
RAID 1 y RAID 5 son iguales pero de diferentes fabricantes
D
RAID 1 es para SSDs y RAID 5 es exclusivo para discos SAS
Correcto: RAID 1 (mirror) escribe los mismos datos en 2 discos; si uno falla, el otro tiene la copia exacta (desperdicia el 50% del espacio). RAID 5 distribuye datos y bloques de paridad entre 3 o más discos con mejor aprovechamiento del espacio.
Pregunta 18
¿Qué es el "bonding" o "teaming" de interfaces de red en un servidor?
A
Un tipo de cable de red especial para servidores de alta velocidad
B
La configuración de múltiples interfaces de red como una sola lógica, que provee redundancia y/o mayor ancho de banda
C
El proceso de unir físicamente dos servidores en un rack
D
Un protocolo para conectar servidores con storage externo
Correcto: El bonding/teaming combina múltiples interfaces de red en una sola lógica. Si una placa de red o cable falla, el tráfico continúa por las otras interfaces sin interrupción, eliminando la red como SPOF.
Pregunta 19
Un servidor tiene un ventilador que falla. ¿Qué hace el sistema automáticamente para protegerse?
A
Se apaga inmediatamente para proteger los componentes del calor
B
Incrementa la velocidad de los ventiladores restantes para compensar y genera una alarma para que el técnico reemplace el módulo defectuoso
C
Migra las cargas de trabajo al servidor de backup automáticamente
D
Reduce el procesamiento a la mitad para generar menos calor
Correcto: Los servidores con ventiladores redundantes implementan compensación automática: al fallar uno, los restantes aumentan RPM. El BMC (iLO/iDRAC) registra el evento y puede enviar alertas al administrador. El técnico puede reemplazar el módulo en caliente.
Pregunta 20
¿Por qué en un datacenter cada fuente de alimentación redundante se conecta a un circuito eléctrico diferente?
A
Para reducir el consumo eléctrico total del servidor
B
Para que si falla un circuito eléctrico o UPS completo, la otra fuente siga alimentando el servidor desde el circuito alternativo, sin interrupción
C
Porque los servidores de alta potencia requieren alimentación trifásica balanceada
D
Para cumplir con regulaciones de seguridad eléctrica obligatorias
Correcto: Si ambas fuentes se conectan al mismo circuito, una falla eléctrica total tira el servidor igualmente. Conectar cada fuente a un circuito independiente (idealmente con su propio UPS) elimina la alimentación como SPOF.
