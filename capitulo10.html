Herramientas Administrativas

El Panel de Control de Herramientas Administrativas es un conjunto de accesos directos a utilidades que permiten supervisar y configurar el funcionamiento de Windows. Evolucionó con cada versión: Windows 7 lo tenía limitado, Windows 8.1 agregó muchas utilidades nuevas, y Windows 10 afinó el conjunto disponible.

🆕
Windows 11 — Cambio de nombre: En Windows 11 la carpeta "Herramientas Administrativas" fue renombrada a "Windows Tools" (Herramientas de Windows). Se accede desde el Panel de Control → Sistema y seguridad → Windows Tools, o buscando "Windows Tools" en el menú Inicio. Todas las utilidades siguen siendo las mismas, solo cambió el nombre del contenedor.
El Panel de Herramientas Administrativas de Windows 10 lista 20 accesos directos, incluyendo Computer Management, Event Viewer, Services, Registry Editor, Performance Monitor, Windows Memory Diagnostic y más.
Administración de Computadoras

La consola de Administración de Computadoras (compmgmt.msc) centraliza el acceso a tres grupos de utilidades en una sola herramienta. También permite conectarse y administrar equipos remotos en la red.

  • Herramientas del sistema: Visor de eventos, Carpetas compartidas, Usuarios y grupos locales, Rendimiento, Administrador de dispositivos.
  • Almacenamiento: Administración de discos.
  • Servicios y aplicaciones: Servicios, WMI Control.
La consola Administración de Computadoras (compmgmt.msc) con sus tres secciones: Herramientas del sistema, Almacenamiento y Servicios y aplicaciones.
Visor de Eventos

El Visor de Eventos (eventvwr.msc) permite ver el historial de eventos del sistema, aplicaciones y seguridad. Windows clasifica los eventos por nivel:

NivelSignificado
InformaciónEvento exitoso. El controlador o programa se ejecutó correctamente.
AdvertenciaPosible problema con un componente de software. No es crítico aún.
ErrorExiste un problema pero no se requiere acción inmediata.
CríticoRequiere atención inmediata. Fallas o bloqueos del sistema o software.
Auditoría de éxitoSolo en seguridad. Ejemplo: inicio de sesión exitoso.
Auditoría de fallaSolo en seguridad. Ejemplo: intentos fallidos de inicio de sesión.
El Visor de Eventos muestra el resumen de eventos administrativos con conteo de eventos críticos, de error y de advertencia en las últimas horas.
Usuarios y Grupos Locales

Usuarios y grupos locales permite crear y gestionar cuentas de usuario y asignarlas a grupos con permisos predefinidos. Windows tiene tres grupos predeterminados:

  • Administradores: control total del sistema y acceso a todas las carpetas.
  • Usuarios: pueden ejecutar aplicaciones y acceder a impresoras. Tienen un perfil persistente en el sistema.
  • Invitados: perfil temporal creado al iniciar sesión y eliminado al cerrarla. Deshabilitado por defecto.
La sección Usuarios y Grupos Locales dentro de Computer Management, mostrando las cuentas disponibles incluyendo Administrator, Guest y cuentas personalizadas.
Servicios

La consola de Servicios (services.msc) permite administrar todos los servicios del sistema local y remotos. Un servicio es un tipo de aplicación que se ejecuta en segundo plano para cumplir una función específica o esperar solicitudes.

Buena práctica de seguridad: Solo iniciar los servicios necesarios. Cada servicio activo es una posible superficie de ataque. Deshabilitar servicios innecesarios reduce el riesgo.

La consola Servicios (services.msc) lista todos los servicios con su descripción, estado (Running/Stopped) y tipo de inicio (Automatic, Manual, Disabled).
Otras herramientas administrativas clave

📈 Monitor de Rendimiento

Crea informes detallados de contadores específicos de CPU, RAM, disco y red. Más avanzado que el Administrador de tareas.

📷 Administración de Impresión

Vista centralizada de todas las impresoras disponibles. Gestiona colas, drivers y permite implementar configuraciones de impresoras en red via políticas de grupo.

🧠 Diagnóstico de Memoria

Programa una prueba de RAM al próximo inicio del sistema. Los resultados se guardan en el Visor de Eventos. Ideal para diagnosticar fallas intermitentes.

🗃 Servicios de Componentes

Herramienta para administradores y desarrolladores que gestiona componentes COM (Component Object Model) para aplicaciones empresariales y de internet.

📑 Orígenes de Datos (ODBC)

Agrega, elimina y administra orígenes de datos mediante ODBC (Open Database Connectivity), tecnología que permite que los programas accedan a bases de datos.

📋 Programador de Tareas

Automatiza la ejecución de programas o scripts en horarios definidos, al iniciar el sistema, al iniciar sesión u otros disparadores.

Utilidades del Sistema

Información del Sistema (msinfo32)

Información del sistema (msinfo32) recopila y muestra información detallada sobre hardware, controladores, componentes y configuración del software. Puede exportar un informe completo del equipo a un archivo de texto.

# Cómo abrir Información del sistema
Tecla Win + R → escribir: msinfo32

# O desde el Símbolo del sistema
msinfo32
msinfo32 muestra el resumen del sistema: nombre del SO, versión, fabricante, modelo, procesador, BIOS, tipo de sistema (x64), modo de arranque y más.
Configuración del Sistema (msconfig)

msconfig es la herramienta para identificar y resolver problemas que impiden que Windows inicie correctamente. Tiene cinco pestañas:

General

Elige entre Inicio normal, Inicio con diagnóstico (mínimo de drivers) e Inicio selectivo (configuración personalizada).

Arranque

Selecciona qué SO arrancar (si hay varios) y habilita el Arranque seguro (Safe Boot) para solucionar problemas graves.

Servicios

Muestra y permite deshabilitar servicios individuales al arrancar para diagnosticar cuál causa el problema.

Inicio

En Win 7: lista de apps que inician con Windows. En Win 8.1/10/11: redirige al Administrador de Tareas → pestaña Inicio.

🆕
Windows 11 — Administrador de Tareas rediseñado: En Windows 11 el Task Manager fue completamente rediseñado: nueva interfaz con barra lateral de navegación, nueva función "Modo eficiencia" para limitar el consumo de recursos de procesos individuales, y acceso directo desde Win+X → Administrador de tareas. Las apps de inicio se gestionan desde Configuración → Apps → Inicio.

Herramientas

Acceso directo a herramientas de diagnóstico como Información del sistema, Visor de eventos, UAC y más.

# Cómo abrir Configuración del sistema
Tecla Win + R → escribir: msconfig
El Registro de Windows

El Registro de Windows es la base de datos central donde se almacena toda la configuración del sistema operativo y las aplicaciones. Se organiza jerárquicamente en claves y subclaves (hasta 512 niveles). Existe como archivos de base de datos llamados colmenas.

Cada clave tiene valores que consisten en: nombre del valor, tipo de datos y los datos en sí.

Las cinco claves raíz del Registro de Windows y su contenido: HKLM (hardware), HKCU (usuario actual), HKCR (archivos y accesos directos), HKU (todos los usuarios) y HKCC (perfil de hardware).
Editor del Registro (regedit)

El editor del registro (regedit) permite que un administrador vea y modifique el Registro de Windows. Su uso incorrecto puede causar problemas graves de hardware, aplicaciones o incluso requerir reinstalar el SO.

🔴
Advertencia: Siempre hacer una copia de seguridad del registro antes de realizar cambios. El editor del registro solo debe abrirse desde una búsqueda o desde el símbolo del sistema escribiendo regedit.
regedit mostrando la subclave HKEY_CURRENT_USER\Environment con el valor OneDrive abierto para edición. Se ven las cinco claves raíz en el panel izquierdo.
Microsoft Management Console (MMC)

La Consola de Administración de Microsoft (MMC) permite crear consolas de administración personalizadas agregando herramientas llamadas complementos (snap-ins). Se pueden guardar para reutilizar. Permite combinar en una sola consola exactamente las herramientas que el administrador necesita.

DxDiag — Diagnóstico de DirectX

DxDiag (DirectX Diagnostic Tool) muestra información de todos los controladores y componentes de DirectX instalados. Se ejecuta desde búsqueda o desde la línea de comandos.

DirectX es el entorno de software para aplicaciones multimedia (especialmente juegos): define interfaces para gráficos 2D/3D, audio, codificadores y decodificadores.

dxdiag → ejecutar desde Win+R o CMD
DxDiag muestra la versión de DirectX instalada (DirectX 12), el SO, procesador, memoria RAM y permite navegar por pestañas de Sistema, Pantalla, Sonido e Input.

Administración de Discos

Utilidad Administración de Discos

La utilidad Administración de Discos permite gestionar discos y particiones de forma visual. Se accede desde: clic derecho en "Este equipo" → Administrar, o desde Win+X → Administración de discos.

Permite realizar las siguientes tareas:

  • Ver el estado de cada unidad y partición
  • Ampliar o reducir particiones existentes
  • Asignar o cambiar letras a las unidades
  • Agregar discos y crear arreglos (RAID)
  • Designar la partición activa
  • Convertir discos de básico a dinámico
Administración de Discos mostrando las particiones del Disco 0 (EFI, Windows BitLocker, OEM) y el Disco 1 removible (ADATA DRIVE D:).
Estados de las unidades
EstadoDescripción
En líneaDisco accesible y sin problemas. Estado normal.
CorrectoVolumen que funciona correctamente.
En línea (Errores)Errores de E/S detectados en un disco dinámico.
Sin conexiónDisco dinámico dañado o no disponible.

ExternoDisco dinámico movido desde otra computadora con Windows.
Montaje de una Unidad (ISO)

Montar una unidad implica hacer que un archivo de imagen de disco (ISO) sea accesible como si fuera una unidad física, sin grabarlo en un disco.

Cómo montar en Windows: Abrir el Explorador de archivos → seleccionar el archivo ISO → pestaña "Administrar" en Herramientas de imagen de disco → clic en Montar. El ISO aparece como una unidad de medios extraíble con su propia letra.

También es posible crear un punto de montaje, que hace que una unidad completa aparezca como una carpeta dentro de otra unidad.

El botón Montar en la cinta del Explorador de archivos, y el resultado: el ISO montado aparece como unidad DVD Drive (E:) con el contenido del archivo de imagen accesible.
Arreglos de Discos y Espacios de Almacenamiento
🗇 Arreglos RAID en Discos Dinámicos

Desde Administración de discos se pueden crear volúmenes multidisco en discos dinámicos: volumen distribuido (Spanned), seccionado (Striped/RAID 0), reflejado (Mirrored/RAID 1) y RAID-5. Se necesitan 2 o más discos dinámicos inicializados.

💻 Espacios de Almacenamiento

Disponible desde Windows 8. Tecnología recomendada por Microsoft para agrupar discos físicos en grupos de almacenamiento desde los cuales se crean discos virtuales. Ofrece opciones de duplicado, segmentación y paridad. Más flexible que el RAID tradicional.

Optimización y Verificación de Discos
⚡ Optimizar / Desfragmentar

HDD: el desfragmentador reúne datos no contiguos, mejorando la velocidad de lectura. En Windows 10 se llama "Optimizar". SSD: no desfragmentar; las SSD se optimizan con su propia controladora y el comando TRIM. La herramienta Optimizar unidades permite analizar antes de optimizar.

🔍 Verificación de Errores

Comprueba la integridad de archivos y carpetas, detecta sectores defectuosos e intenta recuperar datos. Acceso: clic derecho en la unidad → Propiedades → pestaña Herramientas → Comprobar. Los resultados se guardan en el Visor de Eventos.

Instalación y Configuración de Aplicaciones

Requisitos del Sistema

Antes de instalar cualquier aplicación, el técnico debe verificar que el equipo cumple los requisitos. Estos suelen especificarse en el empaque o la página de descarga del software:

  • Procesador: velocidad mínima, arquitectura (32/64 bits, x86)
  • RAM: cantidad mínima y recomendada
  • SO y versión: qué versiones de Windows son compatibles
  • Espacio en disco: espacio disponible requerido
  • Dependencias: .NET Framework, Java, Visual C++ Runtime u otros
  • Gráficos: resolución y versión de DirectX
  • Periféricos: si necesita cámara, micrófono, etc.
Ejemplo de tabla de requisitos mínimos y recomendados para una aplicación: SO, procesador, memoria, resolución de pantalla, espacio en disco y conexión de red.
Métodos de Instalación
Los cinco métodos de instalación: Atendido (usuario presente), Silencioso/desatendido (sin interacción), Programado/automatizado (disparado por temporizador), Limpio (sin versiones previas) y Red (desde servidor).

La instalación local se puede realizar desde disco duro, CD/DVD o USB. Si no inicia automáticamente, se busca el instalador en los medios. El archivo del instalador suele tener extensión .EXE o .MSI (Microsoft Silent Installer). Windows 8 y 10 también permiten instalar apps desde la Tienda Microsoft (Microsoft Store).

Modo de Compatibilidad

Las aplicaciones diseñadas para versiones antiguas de Windows pueden no funcionar correctamente en sistemas más nuevos. El Modo de Compatibilidad permite emular el entorno de una versión anterior.

Cómo configurarlo:

  1. Clic derecho en el acceso directo → "Abrir ubicación del archivo"
  2. Clic derecho en el ejecutable → Propiedades
  3. Pestaña Compatibilidad
  4. Ejecutar el Solucionador de problemas o configurar manualmente la versión de Windows
La pestaña Compatibilidad en Propiedades del ejecutable, con la opción de ejecutar el programa en modo de compatibilidad con Windows 8 y ajustes adicionales de color, resolución y DPI.
Desinstalar o Cambiar Programas

Si una aplicación no se desinstala correctamente, pueden quedar archivos en el disco y entradas en el Registro que consumen recursos innecesariamente y ralentizan el sistema.

Microsoft recomienda usar siempre la utilidad Programas y características (Panel de Control) para eliminar, modificar o reparar aplicaciones. Esta guía al usuario en el proceso y elimina todos los archivos instalados.

appwiz.cpl → abre Programas y características
🆕
Windows 11 — Nueva ubicación principal: En Windows 11 Microsoft migró la gestión de apps a Configuración → Aplicaciones → Aplicaciones instaladas. Desde allí se puede desinstalar, modificar y ver el tamaño de cada app. El método clásico appwiz.cpl sigue funcionando pero ya no es el método primario recomendado. Las apps de la Microsoft Store solo pueden gestionarse desde Configuración.
La utilidad Programas y características del Panel de Control mostrando el proceso de desinstalación de Inkscape con opciones de desinstalación personalizadas.
Consideraciones de Seguridad

Permitir que los usuarios instalen software en equipos corporativos es un riesgo de seguridad importante. Los usuarios pueden ser engañados para descargar malware que puede robar datos, infectar otros equipos en la red o causar daños generalizados.

⚠️
Como técnico, es esencial aplicar políticas de instalación de software y asegurarse de que el antimalware (como Windows Defender) esté activo y actualizado en todos los equipos de la organización.
El panel Windows Security (Seguridad de Windows) mostrando el estado de todos los componentes: Virus & threat protection, Account protection, Firewall, App & browser control y Device security.
🆕 Diferencias clave en Windows 11

Resumen de los cambios que el técnico debe conocer al trabajar con Windows 11:

⚙️ Windows Tools

Las "Herramientas Administrativas" ahora se llaman "Windows Tools". Mismas utilidades, nuevo nombre. Buscar "Windows Tools" en el menú Inicio.

📜 Administrador de Tareas

Completamente rediseñado con barra lateral. Nueva función "Modo eficiencia" para throttlear procesos. Startup apps también en Configuración → Apps → Inicio.

📚 Desinstalar Apps

Método principal: Configuración → Aplicaciones → Aplicaciones instaladas. appwiz.cpl sigue funcionando pero no gestiona apps de la Microsoft Store.

💻 Panel de Control

Microsoft continúa migrando configuraciones al app Configuración. El Panel de Control clásico sigue disponible pero se usa cada vez menos. El técnico debe conocer ambos.

🔮 Terminal de Windows

En Windows 11 el menú Win+X muestra Terminal de Windows (reemplaza a PowerShell/CMD). Unifica PowerShell, CMD y WSL en una sola app con pestañas.

🔧 Mismo fondo, nueva capa

msconfig, regedit, Administración de Discos, Servicios, msinfo32 y DxDiag funcionan idéntico que en Windows 10. Solo cambia la interfaz de encima.
