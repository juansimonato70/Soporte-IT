¿Qué es Linux?

Linux es un sistema operativo de código abierto desarrollado por una comunidad global de programadores. Es utilizado en computadoras personales, servidores, mainframes, dispositivos móviles, sistemas embebidos y supercomputadoras.

Al ser código libre, cualquier persona puede utilizarlo, copiarlo, modificarlo y redistribuirlo libremente para cualquier uso, siempre bajo los términos de la licencia GPL de GNU. Un ejemplo cotidiano es Android, el sistema operativo móvil más usado del mundo, que utiliza el núcleo (kernel) Linux como base.

Dato histórico: Linux fue creado en 1991 por el estudiante finlandés Linus Torvalds, quien publicó el código fuente del kernel de forma gratuita. Su mascota oficial es Tux, un pingüino.

Tux, la mascota oficial de Linux. Creado por Larry Ewing en 1996.
¿Dónde se usa Linux hoy?
📱 Dispositivos móviles

Android, el SO más usado del mundo, está basado en el kernel Linux. Más del 70% de los smartphones del mundo corren Linux.

🌐 Servidores web

Más del 96% de los servidores de internet corren Linux. Google, Amazon, Facebook y Wikipedia usan Linux en sus infraestructuras.

🖥️ Supercomputadoras

El 100% de las 500 supercomputadoras más potentes del mundo usan Linux como sistema operativo.

La licencia GPL

La Licencia Pública General GNU (GPL) es la licencia de software libre más utilizada del mundo. Garantiza cuatro libertades fundamentales para los usuarios:

LibertadDescripción
Libertad 0Usar el programa para cualquier propósito, sin restricciones.
Libertad 1Estudiar el funcionamiento del programa y modificarlo según las necesidades.
Libertad 2Distribuir copias del programa para ayudar a otros.
Libertad 3Distribuir copias de las versiones modificadas, para que la comunidad se beneficie.
ℹ️
Código abierto ≠ gratuito: "Open source" significa que el código fuente está disponible para ser revisado y modificado. Aunque Linux suele ser gratuito, el modelo open source no impide que existan versiones comerciales pagas (como Red Hat Enterprise Linux).

Distribuciones de Linux

Una distribución de Linux (o "distro") es un sistema operativo completo basado en el núcleo Linux que incluye paquetes de software adicionales para satisfacer las necesidades de un grupo específico de usuarios. Existen ediciones domésticas, empresariales y para servidores.

La distribución más famosa es Ubuntu, que ha sido una de las que hicieron conocido a Linux en el mundo y lo equiparó a Windows o macOS. Ubuntu no existiría sin Debian, una de las distribuciones más antiguas, sobre la cual Canonical se basó para desarrollarla.

Algunas de las distribuciones Linux más conocidas: Arch, Debian, Fedora, Gentoo, Linux Mint, Kubuntu, openSUSE, Red Hat, Ubuntu y muchas más.
Distribuciones más importantes

🟠 Ubuntu

La más popular para usuarios de escritorio. Fácil de usar, gran comunidad y soporte LTS de 5 años. Ideal para principiantes. Basada en Debian.

🔴 Debian

Una de las más antiguas y estables. Base de Ubuntu y muchas otras distros. Muy usada en servidores. Soporte de la comunidad.

🍃 Linux Mint

Basada en Ubuntu. Interfaz muy similar a Windows, ideal para usuarios que vienen de Windows. Excelente para equipos de gama media-baja.

🔵 Fedora

Patrocinada por Red Hat. Incorpora tecnologías de vanguardia. Popular entre desarrolladores y administradores de sistemas.

⚙️ Red Hat Enterprise

Distribución comercial para empresas. Ofrece soporte técnico certificado. Es la base de CentOS y Rocky Linux.

🦎 openSUSE

Muy estable y configurable. Popular en Europa. Herramienta YaST para administración gráfica del sistema.

Pre-instalación de Linux

Antes de instalar Linux, el técnico debe preparar el entorno y tomar decisiones importantes: qué distribución instalar, si será la única en el equipo o en dual boot con Windows, y verificar la compatibilidad del hardware.

Tipos de instalación
🐧 Solo Linux

Se borra todo el disco y se instala únicamente Linux. Más simple, mejor rendimiento. Ideal para equipos dedicados o servidores.

🪟🐧 Dual Boot

Linux y Windows conviven en el mismo disco en particiones separadas. Al encender, el usuario elige qué SO iniciar. Requiere más cuidado en el particionado.

💻 Máquina Virtual

Linux corre dentro de Windows (o viceversa) usando VirtualBox o VMware. Ideal para aprender sin riesgo de perder datos.

Preparativos
  1. Descargar la imagen ISO de Ubuntu
    Desde ubuntu.com/download. Elegir la versión LTS (la más reciente con soporte largo). El archivo ISO pesa aproximadamente 5 GB.
  2. Descargar Rufus
    Desde rufus.ie. Es la herramienta más confiable para crear el pendrive booteable desde Windows. También puede usarse balenaEtcher (multiplataforma).
  3. Crear el pendrive booteable
    Abrir Rufus, seleccionar la ISO de Ubuntu, elegir el esquema GPT + UEFI para equipos modernos. El proceso tarda unos minutos y deja el USB listo para arrancar.
  4. Configurar el BIOS para arrancar desde USB
    Entrar al BIOS (F2, F10, F12 o DEL), colocar el USB como primer dispositivo de arranque y guardar los cambios con F10.
  5. Tiempo y paciencia
    La instalación de Ubuntu tarda entre 15 y 30 minutos. Más sencilla y rápida que Windows.
Ubuntu puede instalarse desde un pendrive USB o un DVD. El método USB es más rápido y el más recomendado.
Secuencia de arranque

Al encender el equipo con el USB conectado, el sistema sigue la misma secuencia de arranque que en Windows. Una vez que finaliza el POST, el BIOS ubica y lee los ajustes de configuración almacenados en la memoria CMOS. La prioridad del dispositivo de arranque es el orden en el que se comprueban los dispositivos para ubicar la partición de arranque.

Pantalla de BIOS SETUP UTILITY — Boot Device Priority. El primer dispositivo debe ser el CD/DVD o USB para arrancar desde el instalador de Ubuntu.

El BIOS arranca usando la primera unidad con un sector de arranque válido. Este sector contiene el MBR (Registro de Arranque Maestro). En el caso de Linux, el gestor de arranque es GRUB (en lugar de bootmgr.exe de Windows), que permite elegir entre Linux y otros SO instalados.

ℹ️
GRUB vs bootmgr.exe: Mientras Windows usa bootmgr.exe como gestor de arranque, Linux usa GRUB2 (Grand Unified Bootloader). GRUB es más flexible y puede gestionar el arranque de múltiples sistemas operativos, incluido Windows.

Proceso de Instalación de Ubuntu

Con el pendrive listo y el BIOS configurado, al reiniciar el equipo carga el instalador de Ubuntu. La instalación es conocida por ser más simple e intuitiva que la de Windows:

  1. Probar o instalar Ubuntu
    Al arrancar desde el USB, Ubuntu ofrece la opción de "Probar Ubuntu" (Live Session, sin instalar nada) o "Instalar Ubuntu". La sesión de prueba es muy útil para verificar que el hardware funciona correctamente antes de instalar.
  2. Seleccionar idioma y distribución de teclado
    Elegir el idioma del sistema (Español) y la distribución del teclado (Español Latinoamericano o España según corresponda). El instalador detecta la distribución automáticamente en la mayoría de los casos.
  3. Actualizaciones y software de terceros
    El instalador pregunta si descargar actualizaciones durante la instalación y si instalar software de terceros (codecs multimedia, drivers privativos como los de NVIDIA). Se recomienda marcar ambas opciones si hay conexión a internet.
  4. Tipo de instalación — Particionado
    Aquí se toma la decisión más importante. Las opciones son:
    • Borrar disco e instalar Ubuntu: instalación limpia, Ubuntu ocupa todo el disco. La opción más simple.
    • Instalar junto a Windows: dual boot automático. Ubuntu crea su partición al lado de Windows.
    • Algo más (manual): particionado manual avanzado para usuarios con experiencia.
  5. Zona horaria
    Seleccionar la zona horaria en el mapa interactivo. Para Argentina: America/Argentina/Buenos_Aires.
  6. Crear usuario y contraseña
    Ingresar el nombre completo, el nombre de usuario (en minúsculas, sin espacios) y una contraseña segura. A diferencia de Windows, en Linux la contraseña del usuario es esencial para las tareas administrativas (comando sudo).
  7. Instalación automática
    Ubuntu copia los archivos y configura el sistema. El proceso dura entre 15 y 25 minutos. Al finalizar, solicita reiniciar y retirar el USB.
  8. Post-instalación
    Abrir el Actualizador de software y aplicar todas las actualizaciones disponibles. Instalar los drivers privativos desde Configuración → Software y actualizaciones → Controladores adicionales si el equipo tiene GPU NVIDIA o AMD.
Comandos básicos post-instalación
# Actualizar el sistema completo (siempre lo primero)
sudo apt update && sudo apt upgrade -y

# Instalar software esencial
sudo apt install curl wget git build-essential -y

# Ver información del sistema
uname -a    # versión del kernel
lsb_release -a  # versión de Ubuntu

# Ver hardware reconocido
lspci    # dispositivos PCI (gráficos, red, etc.)
lsusb    # dispositivos USB conectados
✅
Ventaja de Linux: Ubuntu incluye por defecto la mayoría de los drivers necesarios. En muchos casos el equipo funciona al 100% sin instalar nada adicional, a diferencia de Windows que requiere instalar cada driver manualmente.

Práctica de Laboratorio — Instalación de Ubuntu

En esta práctica el alumno realizará una instalación completa de Ubuntu. Se recomienda usar VirtualBox (gratuito) para practicar sin riesgo, antes de hacerlo en un equipo real.

  1. Descargar Ubuntu LTS
    Ingresar a ubuntu.com/download/desktop y descargar la última versión LTS disponible (archivo .iso de ~5 GB).
  2. Crear el pendrive booteable con Rufus
    Abrir Rufus, seleccionar la ISO de Ubuntu, configurar GPT + UEFI para equipos modernos o MBR + BIOS para equipos más antiguos. Formatear el USB (mínimo 8 GB).
  3. Crear una VM en VirtualBox (opcional)
    Crear una máquina virtual con: 2 GB de RAM mínimo (recomendado 4 GB), 25 GB de disco virtual, red en modo NAT. Montar la ISO como disco óptico virtual.
  4. Iniciar la instalación
    Arrancar desde el USB o la VM. Usar la opción "Probar Ubuntu" primero para verificar hardware, luego iniciar la instalación completa.
  5. Configurar particiones e instalar
    Elegir "Borrar disco e instalar Ubuntu" para instalación limpia. Completar zona horaria, usuario y contraseña. Dejar que el proceso finalice y reiniciar.
  6. Post-instalación y verificación
    Ejecutar sudo apt update && sudo apt upgrade -y en la terminal. Verificar que el sistema detecta correctamente el hardware: red, audio, video. Instalar drivers adicionales si es necesario.
  7. Explorar el entorno de escritorio
    Identificar el gestor de archivos, la configuración del sistema, el centro de software y la terminal. Practicar los comandos básicos vistos en el capítulo.
