Pregunta 01
¿Qué cambio polémico introdujo Windows 8 respecto al escritorio que fue criticado por la mayoría de los usuarios?
A
Eliminó la Papelera de reciclaje del escritorio
B
Reemplazó el escritorio clásico por la pantalla de inicio con mosaicos (tiles), eliminando el botón Inicio tradicional, lo que desorientó a usuarios de mouse y teclado
C
Eliminó el soporte para múltiples monitores
D
Cambió el sistema de archivos de NTFS a FAT32
Correcto — Opción B: Windows 8 reemplazó el escritorio clásico por la pantalla de inicio Metro (Modern UI) con mosaicos, y eliminó el botón Inicio. Fue muy criticado porque dificultaba el uso con mouse y teclado. Windows 8.1 corrió estas críticas permitiendo iniciar directamente en el escritorio clásico y reintroduciendo funcionalidades para mouse.
Pregunta 02
En Windows 11, ¿cuál es la diferencia más visible del Menú Inicio respecto a Windows 10?
A
El Menú Inicio de Windows 11 tiene más mosaicos en vivo (Live Tiles) que Windows 10
B
El Menú Inicio está centrado en la barra de tareas por defecto y no tiene mosaicos en vivo; muestra apps ancladas y archivos/apps recomendados recientes
C
El Menú Inicio de Windows 11 ocupa toda la pantalla como Windows 8
D
Windows 11 eliminó el Menú Inicio y lo reemplazó por un panel de Widgets
Correcto — Opción B: En Windows 11 el Menú Inicio está centrado en la barra de tareas (puede cambiarse a la izquierda) y se eliminaron los Live Tiles (mosaicos en vivo). Ahora muestra Apps ancladas en la parte superior y una sección de Recomendados con archivos y apps usados recientemente. Es un diseño más simple y limpio.
Pregunta 03
¿Cómo se accede a la personalización del escritorio en Windows 10 de la forma más rápida?
A
Panel de Control → Sistema → Personalización
B
Administrador de Tareas → pestaña Rendimiento
C
Clic derecho en el escritorio → Personalizar, o Configuración → Personalización
D
Explorador de Archivos → Este PC → Propiedades
Correcto — Opción C: La forma más rápida de acceder a la personalización del escritorio es mediante clic derecho en el escritorio → Personalizar. También se puede acceder desde Configuración → Personalización, donde se encuentran todas las opciones: fondo, colores, pantalla de bloqueo, temas, fuentes, menú Inicio y barra de tareas.
Pregunta 04
¿Qué son los temas en Windows y qué elementos incluyen?
A
Son carpetas de plantillas para documentos de Word y Excel
B
Son paquetes que combinan fondo de pantalla, color de acento, sonidos del sistema y cursor del ratón en un solo clic, siendo la forma más rápida de cambiar el aspecto completo de la GUI
C
Son configuraciones solo de los colores de las ventanas y la barra de tareas
D
Son los fondos de pantalla predeterminados que vienen con Windows
Correcto — Opción B: Un tema de Windows es un paquete que incluye: fondo de pantalla (o presentación), color de acento, sonidos del sistema y cursor del ratón. Aplicar un tema cambia todos estos elementos de una vez, siendo la forma más rápida de personalizar la apariencia completa. Se pueden obtener más temas desde Microsoft Store.
Pregunta 05
¿Cómo se puede anclar una aplicación al Menú Inicio en Windows 10?
A
Arrastrando el icono del escritorio al botón Inicio
B
Desde el Panel de Control → Programas → Anclar al Inicio
C
Haciendo clic derecho en la aplicación (en la lista del Menú Inicio o en el escritorio) y seleccionando "Anclar a Inicio"
D
Solo se pueden anclar aplicaciones de la Microsoft Store, no aplicaciones clásicas
Correcto — Opción C: Para anclar una app al Menú Inicio: clic derecho en la aplicación (puede ser desde la lista de apps del Menú Inicio, desde el escritorio o desde el Explorador de archivos) → "Anclar a Inicio". Aparece como mosaico en la sección derecha del Menú Inicio. En Windows 11 se puede anclar desde "Más opciones".
Pregunta 06
En la barra de tareas de Windows 10, ¿qué opción permite que la barra se oculte cuando no se usa el mouse?
A
Usar botones pequeños de la barra de tareas
B
Bloquear la barra de tareas
C
Ocultar automáticamente la barra de tareas en modo escritorio
D
Cambiar la ubicación de la barra de tareas a lateral
Correcto — Opción C: La opción "Ocultar automáticamente la barra de tareas en modo escritorio" hace que la barra se oculte cuando el cursor no está cerca de ella, ampliando el espacio de trabajo. Al mover el mouse al borde inferior, la barra vuelve a aparecer. También existe la misma opción para "modo tablet".
Pregunta 07
¿Cuál es el atajo de teclado más directo para abrir el Administrador de Tareas en Windows?
A
Ctrl+Alt+Supr (abre el Administrador de Tareas directamente)
B
Win+R y escribir taskmgr
C
Ctrl+Shift+Esc (abre el Administrador de Tareas directamente sin pantalla intermedia)
D
Win+X y seleccionar Administrador de tareas
Correcto — Opción C: Ctrl+Shift+Esc abre el Administrador de Tareas directamente, sin pantalla intermedia. Ctrl+Alt+Supr abre la pantalla de seguridad de Windows donde hay que seleccionar el Administrador de Tareas (paso extra). Win+X también ofrece acceso, al igual que clic derecho en la barra de tareas. El más directo es Ctrl+Shift+Esc.
Pregunta 08
En el Administrador de Tareas, ¿en qué pestaña se pueden gestionar las aplicaciones que se inician automáticamente con Windows y se pueden deshabilitar para mejorar el tiempo de arranque?
A
Procesos
B
Servicios
C
Detalles
D
Inicio
Correcto — Opción D: La pestaña "Inicio" del Administrador de Tareas lista todas las aplicaciones que se ejecutan automáticamente al iniciar Windows. Permite habilitarlas o deshabilitarlas individualmente. En Windows 11, las apps de inicio también se pueden gestionar desde Configuración → Apps → Inicio. Deshabilitar apps innecesarias mejora significativamente el tiempo de arranque.
Pregunta 09
¿Qué nueva función agregó Windows 11 al Administrador de Tareas que permite mejorar el rendimiento del sistema y la batería?
A
La pestaña "GPU" para monitorear la tarjeta gráfica en tiempo real
B
El "Modo eficiencia" que limita el consumo de CPU de procesos individuales dándoles menor prioridad, reduciendo el impacto en rendimiento y batería
C
La opción de "Hibernación de procesos" que los suspende completamente
D
Un menú contextual para mover procesos entre núcleos del procesador
Correcto — Opción B: El "Modo eficiencia" (Efficiency mode) es una novedad del Task Manager rediseñado de Windows 11. Al activarlo en un proceso, Windows le da menor prioridad de CPU y limita su consumo de recursos, sin cerrarlo. Es ideal para procesos intensivos en segundo plano (antivirus, indexadores, apps de sincronización) que no necesitan alta prioridad en todo momento.
Pregunta 10
¿Cómo se llama el administrador de archivos en Windows 8 y 10, y cómo se llamaba en Windows 7?
A
Se llamó "Mi PC" en Windows 7 y "Este equipo" en Windows 10
B
Se llama "Explorador de Archivos" en Windows 8/10 y se llamaba "Explorador de Windows" en Windows 7 y versiones anteriores
C
Se llama "Administrador de Archivos" en todas las versiones desde Windows 95
D
Se llama "Explorador de Archivos" en Windows 7, 8 y 10 (el nombre no cambió)
Correcto — Opción B: En Windows 7 y versiones anteriores se llamaba "Explorador de Windows" (Windows Explorer). A partir de Windows 8 se renombró a "Explorador de Archivos" (File Explorer). La funcionalidad es la misma pero la interfaz evolucionó: en Windows 8/10 incorporó la Cinta (Ribbon), que en Windows 11 fue reemplazada por una barra de comandos simplificada.
Pregunta 11
En el Explorador de Archivos de Windows 10, ¿qué es la "Cinta" (Ribbon) y qué pasó con ella en Windows 11?
A
Es la barra de dirección donde se escribe la ruta de la carpeta; en Windows 11 se eliminó completamente
B
Es la barra de herramientas organizada en pestañas (Inicio, Compartir, Vista) que agrupa las acciones comunes; en Windows 11 fue reemplazada por una barra de comandos simplificada con iconos
C
Es el panel izquierdo de navegación con favoritos y dispositivos; en Windows 11 se movió a la derecha
D
Es el panel de vista previa de archivos; en Windows 11 se integró en el panel lateral
Correcto — Opción B: La Cinta (Ribbon) es la barra de herramientas dividida en pestañas (Inicio, Compartir, Vista) que apareció en Windows 8 y se mantuvo en Windows 10. Las pestañas cambian según lo seleccionado. En Windows 11 (22H2) fue reemplazada por una barra de comandos simplificada con iconos para las acciones más frecuentes, más moderna y menos compleja visualmente.
Pregunta 12
¿Cuál es la diferencia principal entre la app "Configuración" y el "Panel de Control" en Windows 10?
A
La app Configuración solo funciona con pantallas táctiles; el Panel de Control es para mouse y teclado
B
La app Configuración es la interfaz moderna y táctil para configuraciones habituales; el Panel de Control es la interfaz clásica con acceso a configuraciones más avanzadas y técnicas
C
Son idénticos en funcionalidad; solo difieren en el estilo visual
D
El Panel de Control fue eliminado en Windows 10 y reemplazado completamente por Configuración
Correcto — Opción B: La app Configuración es la interfaz moderna y táctil que cubre la mayoría de configuraciones del usuario (sistema, red, personalización, cuentas, actualizaciones). El Panel de Control es la interfaz clásica que contiene opciones más avanzadas, herramientas administrativas y configuraciones que aún no migraron a Configuración. Microsoft continúa migrando opciones del Panel a Configuración en cada actualización.
Pregunta 13
¿Qué es el "Martes de parches" y por qué es importante para el técnico de soporte?
A
Es el día en que Microsoft lanza nuevas versiones de Windows, generalmente en verano
B
Es el nombre informal del segundo martes de cada mes, cuando Microsoft publica actualizaciones de seguridad y parches críticos para Windows y otros productos; el técnico debe estar atento por si las actualizaciones causan problemas en los equipos
C
Es el día en que se deben hacer manualmente las copias de seguridad de los sistemas
D
Es cuando Microsoft publica los parches de Windows solo para usuarios con suscripción Premium
Correcto — Opción B: El "Martes de parches" (Patch Tuesday) es el segundo martes de cada mes cuando Microsoft publica actualizaciones de seguridad, actualizaciones críticas y parches para Windows y otros productos como Office. El técnico debe conocer esta fecha porque: 1) debe verificar que los equipos apliquen las actualizaciones y 2) a veces una actualización puede causar problemas que requieren intervención técnica.

B
Configuración → Actualización y seguridad → Windows Update → Buscar actualizaciones
C
Administrador de Tareas → Servicios → Windows Update → Iniciar
D
Explorador de Archivos → Este PC → Propiedades → Actualizaciones

Pregunta 15
¿Qué es un punto de restauración y qué NO puede hacer la utilidad "Restaurar sistema"?
A
Es una copia de todos los archivos del equipo; puede recuperar documentos eliminados por error
B
Es una instantánea del estado del sistema (registro y controladores); NO realiza copias de seguridad de archivos personales ni recupera archivos eliminados o dañados
C
Es una copia de seguridad completa del disco; puede recuperar cualquier archivo perdido
D
Es una imagen de la RAM; solo sirve para recuperar de bloqueos del sistema en caliente
Correcto — Opción B: Un punto de restauración guarda el estado del sistema operativo (registro de Windows, configuración del sistema, controladores instalados) en un momento específico. La utilidad "Restaurar sistema" puede volver a ese estado si algo sale mal, pero NO recupera archivos personales eliminados ni hace copias de seguridad de documentos. Para proteger datos personales se usa el Historial de archivos u otro sistema de backup.
Pregunta 16
¿Cuándo recomienda el capítulo crear un punto de restauración?
A
Solo cuando el equipo ya tiene problemas y no inicia correctamente
B
Antes de actualizar el SO, instalar o actualizar hardware, instalar una aplicación o driver, o hacer cambios importantes al registro
C
Una vez al año como mantenimiento anual de rutina
D
Solo antes de apagar el equipo para fin de semana
Correcto — Opción B: El punto de restauración debe crearse como medida preventiva antes de: actualizar el sistema operativo, instalar o actualizar hardware, instalar una aplicación nueva, instalar o actualizar un driver, o realizar cambios al registro. Es la "red de seguridad" del técnico: si algo sale mal después de los cambios, se puede volver al estado anterior en minutos.
Pregunta 17
¿Qué es el "Historial de archivos" (File History) y desde qué versión de Windows está disponible?
A
Es el historial de navegación web; disponible desde Windows 7
B
Es una función que guarda periódicamente copias de las carpetas personales (Documentos, Imágenes, Música, Videos, Escritorio) en un disco externo o red; disponible desde Windows 8
C
Es el registro de todos los archivos ejecutados en el sistema; disponible desde Windows Vista
D
Es una copia completa de imagen del sistema; disponible desde Windows 10
Correcto — Opción B: El Historial de archivos (File History) es una función de backup disponible desde Windows 8 que guarda copias periódicas de las carpetas del usuario (Documentos, Música, Imágenes, Videos y Escritorio) en un disco externo o red. Permite recuperar versiones anteriores de archivos individuales. Se configura en Configuración → Actualización y seguridad → Copia de seguridad.
Pregunta 18
¿Cuál es la diferencia entre una "copia de seguridad (backup)" y un "punto de restauración"?
A
Son lo mismo: ambos protegen los datos del usuario y el sistema operativo
B
El punto de restauración protege el sistema operativo (registro, drivers); la copia de seguridad protege los datos personales del usuario. Ambos son necesarios para una estrategia de protección completa
C
El backup copia el sistema operativo; el punto de restauración copia los datos del usuario
D
Solo existe diferencia de velocidad: los puntos de restauración son más rápidos de crear que un backup completo
Correcto — Opción B: Son complementarios y protegen cosas diferentes. El punto de restauración guarda el estado del SO (registro, configuración, drivers) pero NO los archivos personales. El backup (Historial de archivos, OneDrive, imagen del sistema) protege los datos personales del usuario. Una estrategia de mantenimiento completa requiere ambos: puntos de restauración para el sistema y backups para los datos.
Pregunta 19
En Windows 11, ¿hacia qué solución de backup empuja Microsoft como opción principal?
A
El Historial de Archivos en un disco externo USB
B
La herramienta clásica de Copia de seguridad de Windows 7, que sigue funcionando
C
OneDrive como solución de respaldo principal en la nube, integrado con la cuenta de Microsoft y con historial de versiones de archivos
D
Una imagen del sistema en DVD como en Windows 7
Correcto — Opción C: En Windows 11 Microsoft promueve OneDrive como la solución principal de backup. OneDrive sincroniza automáticamente los archivos en la nube, permite acceder desde cualquier dispositivo y tiene historial de versiones (protección contra ransomware). El Historial de Archivos sigue disponible pero se accedé desde nuevas ubicaciones en Configuración. La recomendación profesional es la regla 3-2-1: 3 copias, 2 medios distintos, 1 fuera de sitio.
Pregunta 20
¿Qué novedad del Explorador de Archivos se introdujo en Windows 11 22H2 que lo acerca a los navegadores web modernos?
A
La posibilidad de agregar marcadores de carpetas como favoritos en la barra lateral
B
Soporte para pestañas: permite abrir múltiples carpetas en una sola ventana del Explorador, similar a las pestañas de un navegador
C
Integración con el historial de navegación de Microsoft Edge
D
La posibilidad de navegar a sitios web directamente desde la barra de dirección
Correcto — Opción B: Windows 11 22H2 (segunda actualización de 2022) introdujo pestañas en el Explorador de Archivos. Permite abrir múltiples carpetas en una sola ventana, similar a las pestañas de un navegador. Fue una de las funciones más solicitadas por la comunidad de usuarios durante años. También se agregó el panel "Inicio" para acceso rápido a archivos recientes y una integración mejorada con OneDrive.
