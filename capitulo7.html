Sistemas Operativos de Windows

Microsoft Windows es el sistema operativo de escritorio más utilizado del mundo. A lo largo de los años ha evolucionado incorporando nuevas interfaces, mejoras de seguridad y soporte para hardware moderno.

Como técnico de soporte, es fundamental conocer las versiones activas, sus características y cuáles siguen recibiendo actualizaciones de seguridad. Un equipo con un SO sin soporte es un equipo vulnerable.

¿Qué es un sistema operativo? Software fundamental que gestiona el hardware y proporciona servicios comunes para los programas. Actúa como intermediario entre el usuario y el hardware de la computadora.

Los tres sistemas operativos más utilizados: Windows, Ubuntu (Linux) y macOS.

Requisitos de Sistema Compatibles

Para recomendar un SO, el técnico debe analizar las limitaciones presupuestarias del cliente, saber cómo se utilizará la computadora y determinar qué tipos de aplicaciones se instalarán. Las siguientes preguntas orientan la decisión:

  • ¿El cliente usa aplicaciones comerciales empaquetadas? En el empaque se detallan los SO compatibles con la aplicación.
  • ¿El cliente usa aplicaciones desarrolladas a medida? El programador especifica qué sistema operativo utilizar.
  • ¿Cuándo fue fabricado el equipo? Hardware muy antiguo puede no ser compatible con Windows 11.
  • ¿Tiene presupuesto para adquirir licencia o conviene aprovechar la activación digital vinculada al hardware?

Arquitectura de 32 y 64 Bits

La arquitectura del procesador determina qué versión de Windows puede instalarse y cuánta RAM puede utilizarse. Esta diferencia impacta directamente en el rendimiento y la compatibilidad de software.

Comparativa oficial: diferencias clave entre las arquitecturas de 32 bits (x86-32) y 64 bits (x86-64).
⚙️ 32 bits (x86)
  • Direcciona hasta 4 GB de RAM (en la práctica ~3.2 GB usables).
  • Compatible con hardware antiguo.
  • Solo ejecuta aplicaciones de 32 bits.
  • Windows 11 no tiene versión de 32 bits.
  • Menor seguridad: sin ASLR completo ni DEP avanzado.
🚀 64 bits (x64)
  • Puede direccionar terabytes de RAM (según edición de Windows).
  • Estándar en todos los equipos modernos.
  • Ejecuta apps de 32 y 64 bits (mediante WOW64).
  • Obligatorio para Windows 11.
  • Mayor seguridad y rendimiento en todas las tareas.
¿Cómo verificar la arquitectura?
# Método 1 — Información del sistema
Tecla Windows + R → msinfo32 → ver "Tipo de sistema"

# Método 2 — Configuración
Configuración → Sistema → Acerca de → Tipo de sistema

# Método 3 — Símbolo del sistema
wmic cpu get AddressWidth
Resultado 64 = 64 bits | Resultado 32 = 32 bits

Regla práctica: Si el equipo tiene más de 4 GB de RAM instalada, siempre instalar la versión de 64 bits. Un SO de 64 bits puede ejecutar apps de 32 bits, pero no al revés.

Pre-instalación de Windows

Una instalación exitosa comienza mucho antes de arrancar el instalador. La etapa de pre-instalación es donde el técnico toma decisiones críticas, realiza respaldos y prepara los medios de instalación.

🔴
Lo primero siempre: hacer un RESPALDO. Antes de cualquier instalación se deben guardar todos los datos importantes del cliente: documentos, fotos, licencias de software, exportar favoritos del navegador y configuraciones de correo. Una instalación puede salir mal y los datos perdidos son irrecuperables.
Tipos de instalación
🧹 Instalación limpia

Se borra todo el contenido del disco y se instala Windows desde cero. Recomendada cuando hay virus, corrupción del sistema o cambio de versión mayor.

⬆️ Actualización

Se instala la nueva versión sobre la existente, conservando archivos, apps y configuraciones. Ejemplo: Windows 10 → Windows 11.

📦 Migración

Se transfieren datos y configuraciones de una PC vieja a una nueva. Se usa USMT o software de terceros para no perder nada.

Preparativos
  1. Descargar la imagen ISO oficial
    Desde el sitio de Microsoft usando la Media Creation Tool (gratuita). Siempre descargar desde la fuente oficial para evitar versiones modificadas o con malware.
  2. Crear el pendrive booteable
    Grabar la ISO en un USB de mínimo 8 GB usando Rufus (recomendado) o la propia Media Creation Tool. Elegir esquema GPT + UEFI para equipos modernos, o MBR + BIOS para equipos antiguos.
  3. Configurar el BIOS/UEFI
    Entrar al BIOS (generalmente F2, F10, F12 o DEL al encender) y colocar el USB como primer dispositivo de arranque. Guardar con F10.
  4. Tiempo y paciencia
    La instalación tarda entre 20 y 50 minutos. Con drivers, actualizaciones y apps del cliente puede llevar 2 a 3 horas en total.
El pendrive booteable es el método más rápido y confiable para instalar Windows.
Secuencia de arranque del sistema

Al encender el equipo, antes de que Windows cargue, el sistema sigue una secuencia precisa. Una vez que finaliza el POST, el BIOS ubica y lee los ajustes de configuración almacenados en la memoria CMOS. La prioridad del dispositivo de arranque es el orden en el que se comprueban los dispositivos para ubicar la partición de arranque.

Pantalla de BIOS SETUP UTILITY mostrando Boot Device Priority. El primer dispositivo es el DVD/USB (CD/DVD:3S-ATAPI), el segundo el disco rígido (SATA:3M-ST31000340).

El BIOS arranca la computadora utilizando la primera unidad que contenga un sector de arranque válido. Este sector contiene el Registro de arranque maestro (MBR). El MBR identifica el Registro de arranque del volumen (VBR), que carga el administrador de arranque, y para Windows es bootmgr.exe.

#PasoDescripción
1Power OnLa fuente envía energía. El procesador ejecuta instrucciones desde la ROM.
2POSTPower-On Self-Test: el BIOS/UEFI verifica RAM, CPU, video y dispositivos. Errores generan códigos de bip o mensajes en pantalla.
3BIOS + CMOSEl BIOS lee la configuración almacenada en CMOS (alimentada por la pila interna), incluyendo la prioridad del dispositivo de arranque.
4MBR / GPTEl BIOS busca el primer dispositivo con sector de arranque válido. En discos MBR lee el Registro de Arranque Maestro. En GPT accede a la partición EFI.
5VBR → bootmgr.exeEl MBR identifica el VBR (Volume Boot Record), que carga el administrador de arranque de Windows: bootmgr.exe.
6BCDbootmgr.exe lee la base de datos BCD (Boot Configuration Data). Si hay varios SO, muestra el menú de selección.
7KernelSe carga winload.exe → ntoskrnl.exe (kernel) → drivers esenciales → servicios del sistema → pantalla de inicio de sesión.

Proceso de Instalación

Con el pendrive booteable preparado y el BIOS configurado para arrancar desde USB, el proceso de instalación puede comenzar. A continuación el flujo paso a paso para una instalación limpia de Windows 10/11:

  1. Inicio del instalador
    Al arrancar desde el USB aparece la pantalla de instalación. Seleccionar idioma, formato de hora y distribución del teclado. Clic en "Instalar ahora".
  2. Clave de producto
    Ingresar la clave de licencia. Si no se dispone de ella, clic en "No tengo una clave de producto" para activar luego. En equipos con activación digital vinculada al hardware, la activación es automática al conectarse a internet.
  3. Tipo de instalación
    Elegir "Personalizada: instalar solo Windows (avanzado)" para instalación limpia. La opción "Actualizar" conserva archivos y apps del SO anterior.
  4. Particionado del disco
    Se muestra el disco disponible. Para instalación limpia: eliminar todas las particiones y seleccionar el espacio sin asignar. Windows crea automáticamente las particiones necesarias (EFI, Reservada del sistema, Primaria).
  5. Copia e instalación de archivos
    Windows copia los archivos y el sistema se reinicia automáticamente varias veces. Proceso de 15 a 40 minutos según el hardware. No desconectar el pendrive hasta que finalice.
  6. Configuración inicial (OOBE)
    El asistente guía para elegir región, teclado, conectarse a internet y configurar la cuenta de usuario (Microsoft o local).
  7. Post-instalación: drivers y actualizaciones
    Instalar drivers del fabricante (chipset → red → gráficos → audio), ejecutar Windows Update y configurar las aplicaciones del cliente.

Orden recomendado post-instalación: 1° Chipset — 2° Red — 3° Gráficos — 4° Audio/Bluetooth — 5° Windows Update (reiniciar) — 6° Antivirus — 7° Aplicaciones del usuario.

🛠️

Instalar Windows 11 sin cumplir todos los requisitos

Microsoft impuso requisitos estrictos para Windows 11 (TPM 2.0, Secure Boot, CPU compatible). Sin embargo, existen métodos que permiten instalar Windows 11 en equipos que no cumplen todos los requisitos, algo muy útil para el técnico en el campo.

Método 1 — Rufus con opción de bypass

La última versión de Rufus incluye opciones de omisión de requisitos de Windows 11 de forma nativa. Al crear el booteable, Rufus pregunta qué restricciones se desean omitir:

🔓 Opciones de bypass en Rufus
  • Remover requisito de TPM 2.0 y Secure Boot
  • Remover requisito de RAM (4 GB mínimo)
  • Remover requisito de disco (64 GB mínimo)
  • Configurar cuenta local (sin cuenta Microsoft)
  • Deshabilitar recopilación de datos (telemetría)
📋 Pasos con Rufus
  1. Descargar la última versión desde rufus.ie
  2. Seleccionar la ISO de Windows 11
  3. Configurar el USB (GPT + UEFI o MBR según equipo)
  4. Al hacer clic en EMPEZAR, aparece el cuadro de opciones
  5. Marcar las opciones deseadas y confirmar
  6. Iniciar el equipo desde el USB normalmente
✅
El método con Rufus es el más sencillo y recomendado. Las opciones de bypass se integran directamente en la instalación sin pasos adicionales, y funcionan en equipos con BIOS Legacy y MBR también.
Método 2 — Saltear la conexión a internet durante la instalación

Durante la configuración inicial de Windows 11 (OOBE), en la edición Home Microsoft obliga a conectarse a internet y crear una cuenta Microsoft. Para evitar esto y usar una cuenta local sin conexión, existe un truco con la consola:

# Cuando aparece la pantalla de "Vamos a conectarte a una red":

1. Presionar  Shift + F10  → se abre el Símbolo del sistema (CMD)
2. Escribir el siguiente comando y presionar Enter:

   oobeypassnro

3. El equipo se reinicia automáticamente
4. Al volver a la pantalla de red, aparece la opción:
   "No tengo acceso a internet" → seguir con cuenta local
ℹ️
¿Qué hace oobe\bypassnro? Modifica un valor del registro de Windows para que el asistente de configuración (OOBE) no requiera conexión a internet, habilitando la opción de crear una cuenta local directamente.
⚠️
Importante: Este comando solo funciona durante la instalación, en la pantalla de configuración inicial. No funciona en Windows ya instalado. También puede usarse en Windows 10 si la pantalla de red bloquea el avance.

⚠️
Instalar Windows 11 en hardware no compatible puede significar que Microsoft no garantice actualizaciones futuras en ese equipo. El técnico debe informar al cliente sobre este punto antes de proceder.

Práctica de Laboratorio

En esta práctica guiada el alumno realizará una instalación completa de Windows. Se puede usar VirtualBox (gratuito) o VMware para simular el proceso sin riesgo de perder datos en equipos reales.

  1. Descargar la ISO oficial de Windows 10 o 11
    Ingresar al sitio de Microsoft, descargar la Media Creation Tool y generar la imagen ISO en 64 bits.
  2. Crear un pendrive booteable con Rufus
    Instalar Rufus, seleccionar la ISO, elegir el esquema adecuado y crear el booteable. Si se usa Win 11, activar las opciones de bypass si el equipo no cumple todos los requisitos.
  3. Configurar la VM o el BIOS del equipo
    En VirtualBox: crear VM con 4 GB RAM, 60 GB de disco, montar la ISO. En equipo real: configurar el USB como primer dispositivo de arranque en el BIOS.
  4. Realizar la instalación limpia
    Seguir el proceso completo: idioma, tipo personalizado, particionado, copia de archivos, configuración OOBE. Usar oobe\bypassnro si se quiere evitar la cuenta Microsoft.
  5. Post-instalación: drivers y actualizaciones
    Instalar todos los drivers en el orden recomendado, ejecutar Windows Update hasta que no queden pendientes, y verificar en el Administrador de dispositivos que no hay errores.
  6. Documentar el proceso
    Redactar un informe con las especificaciones del equipo, versión instalada, drivers instalados, problemas encontrados y soluciones aplicadas.
